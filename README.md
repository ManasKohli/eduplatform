# D4Y Dental Pathway Program

A lightweight, responsive React website for Dentistry for Youth's Dental Pathway Program. It is built with Vite and can be deployed as a static site.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The production site is written to `dist/`. Deploy that folder to any static hosting provider, including Vercel, Netlify, or GitHub Pages. No server-side runtime is required.
